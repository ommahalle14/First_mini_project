# _MINI PROJECT_
# Creating awareness towards nature and animals
### Technologies used 
- 1.	HTML → Structure and content
- 2.	CSS → Styling and layout
- 3.	JavaScript → Interactivity (poll voting)
- 4.	Responsive Design → Mobile-friendly layout
- 5.	Multimedia → Images and embedded videos
- 6.	Forms → User input collection
- 7.	Navigation & Anchors → Smooth scrolling between sections

### Features

- My webpage creates an awareness towards nature animals and sea creatures.
- It gives info about how should we protect our enviournment and help animals by feeding them.
- It gives information about animals and nature conservation from Wikipedia.
- Also controversy on sea mining.
- A registration form is given to those who wants to participate with us.

### How to Run the Project
first extract the zip from Downloads then find the folder of project on your local system.
Note:- for linux and Mac, the folder will be stored in Downloads
if it is in Downloads folder then
```sh
cd Downloads/mini_project
```
if it is in your home directory(~) then
```sh
cd ./mini_project
```
now open the html file using command or u can use Gui also
```sh
open miniproject1.html
```
